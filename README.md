# IT English — Квиз для подготовки к КМ3

Веб-тренажёр для подготовки к контрольной **КМ3** по курсу
*Essential English for IT students. Part 2*. Покрывает все 45 вопросов из
`Вопросы_ИТ_КМ 3.pdf` (Internet, Search Engines, Programming, Web Design, SEO,
Malware, Data Security, Neural Networks, IoT, HLAI).

Интерфейс — русский, учебный контент (вопросы и образцовые ответы) — английский.

## Режимы

- **🎓 Экзамен (8)** — случайно подбирает 8 вопросов, как на реальной КМ3.
  Открываешь образцовый ответ и отмечаешь «Знаю / Повторить», в конце — сводка.
- **🗂️ Карточки (45)** — все вопросы с ответами, фильтр по теме, отметка
  «выучено» (сохраняется в браузере через `localStorage`).
- **✅ Тест** — вопросы с вариантами по ключевым фактам, авто-проверка и счёт.

## Запуск локально

Просто открыть `index.html` в браузере, либо поднять статический сервер:

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

## Стек

Чистый HTML + CSS + JavaScript, без зависимостей и сборки. Размещается на
GitHub Pages как статика.

## Структура

```
index.html        # разметка и переключатель режимов
css/style.css     # стили
js/data.js        # 45 вопросов + образцовые ответы + банк MCQ
js/app.js         # логика режимов, скоринг, прогресс
```

## Источник

Вопросы взяты из `Вопросы_ИТ_КМ 3.pdf`. Образцовые ответы составлены по
содержанию курса Essential English for IT students. Part 2 и предназначены для
самоподготовки.
